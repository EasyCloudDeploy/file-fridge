How Criteria Matching Works (Keep-in-Hot Logic)

In File Fridge, Criteria define what files should STAY in hot storage. Files must match ALL enabled criteria to remain in hot storage. If a file fails to match ANY enabled criterion, it is considered inactive and will be automatically moved to cold storage during the next scan.

Criteria Examples (To Keep Files in Hot Storage)
  • Keep files modified in the last 30 minutes (move older to cold): Type: mtime, Operator: <, Value: 30
  • Keep files accessed in the last 1 day (1440 minutes) (move older to cold): Type: atime, Operator: <, Value: 1440
  • Keep files smaller than 1GB (move larger files to cold): Type: size, Operator: <, Value: 1G
  • Keep only .log files in hot storage (move all other files to cold): Type: name, Operator: matches, Value: *.log
  • Keep only regular files in hot storage (move directories/links to cold): Type: type, Operator: =, Value: f
